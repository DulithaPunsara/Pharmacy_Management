
This advanced pharmacy management system, built with React for the frontend and Spring Boot for the backend. The system is designed to simplify pharmacy operations, improve patient care, and ensure regulatory compliance.

Key Features: 
💊 Drug Management by Pharmacists:

✅ Add and manage drug details (name, dosage, manufacturer, price) 

✅ View Drug: View, edit, and remove drug information with ease.

✅ Edit Drug: Edit drug details as needed.

✅ Remove Drug: Delete drugs from the system when they are no longer in stock.

🛒 Customer Functions:

☑ Search for drugs by name.

☑ Place orders through a seamless cart experience.

☑ Automatic order cancellation after 24 hours for unconfirmed orders.


As a full-stack project, it was a rewarding experience working across both frontend and backend technologies to deliver a robust solution.
